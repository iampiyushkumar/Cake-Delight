# 🛒 Cake Delight - Order Service

The **Order Service** is a core microservice within the **Cake Delight** microservices ecosystem. It is responsible for managing customer shopping baskets, processing checkout requests, saving permanent orders to MongoDB, and publishing asynchronous `ORDER_CREATED` events to Redis via **BullMQ** for downstream processing (e.g., payment, notification, inventory services).

### 🔄 Step-by-Step Checkout Flow:
1. **Request Intake:** Client sends a `POST /api/orders/checkout` request with `userId` and `shippingAddress`.
2. **Basket Retrieval:** The controller queries MongoDB to verify the user's active `Basket`.
3. **Order Creation:** Saves a new document in the `Orders` collection with `status: "PENDING"`.
4. **Event Queueing:** Pushes an `ORDER_CREATED` event containing order payload (`orderId`, `userId`, `items`, `totalPrice`) into the Redis BullMQ queue (`order-events`).
5. **Basket Cleanup:** Clears items and resets `totalPrice` to `0` in the user's `Basket`.
6. **Response:** Returns `201 Created` with the newly created Order details.

## 🗄️ Database Schemas (MongoDB / Mongoose)

The service interacts with two primary Mongoose models:

### 1. Basket Model (`models/Basket.js`)
Stores real-time, active items added by users before checkout. Each user has exactly one basket (`userId` is unique).

```javascript
// basketItemSchema
{
  productId: { type: String, required: true },
  name: { type: String, required: true },
  price: { type: Number, required: true },
  quantity: { type: Number, required: true, default: 1 }
}

// basketSchema
{
  userId: { type: String, required: true, unique: true },
  items: [basketItemSchema],
  totalPrice: { type: Number, required: true, default: 0 },
  timestamps: true
}

Order modal 
// orderItemSchema
{
  productId: { type: String, required: true },
  name: { type: String, required: true },
  price: { type: Number, required: true },
  quantity: { type: Number, required: true }
}

// orderSchema
{
  userId: { type: String, required: true },
  items: [orderItemSchema],
  totalPrice: { type: Number, required: true },
  shippingAddress: { type: String, required: true },
  status: {
    type: String,
    enum: ['PENDING', 'PAID', 'SHIPPED', 'CANCELLED'],
    default: 'PENDING'
  },
  timestamps: true
}

⚡ Redis & BullMQ Integration

# Connect to Redis CLI inside Docker
docker exec -it cake_delight_redis redis-cli

# Check queue keys generated by BullMQ
KEYS bull:order-events:*

# View waiting jobs in the queue
LRANGE bull:order-events:wait 0 -1

# Inspect job details & payload for Job ID 1
HGETALL bull:order-events:1
